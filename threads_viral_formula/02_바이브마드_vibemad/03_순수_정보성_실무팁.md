### - [ ] [글 01] 디자인/UX: 촌스러운 웹사이트 1초 만에 고급스럽게 바꾸는 3대 치트키
**[1/4]**
AI로 홈페이지 만들었는데  
"기능은 다 되는데 왜 이렇게 아마추어가 만든 것처럼 촌스럽지?"  
라는 느낌 받아본 적 있으신가요?

디자인 감각 없어도 됨.  
딱 3가지만 수정하면 순식간에 전문 에이전시 퀄리티로 바뀌는  
CSS/UI 치트키 3가지: 1/4

**[2/4]**
1. **폰트 행간(Line-height)은 무조건 `1.6 ~ 1.7`**  
AI가 기본으로 짜준 코드는 글자 간격이 다닥다닥 붙어있어서 답답해 보임.  
텍스트 스타일 줄 때 `leading-relaxed` 또는 `line-height: 1.6`만 주면 글이 숨을 쉬면서 잡지처럼 읽힙니다.

2. **섹션 위아래 패딩(여백)을 2배로 늘리기**  
초보들은 화면에 여백이 남는 걸 불안해함.  
PC 기준 섹션 상하 여백을 최소 `80px ~ 120px` 이상 시원하게 비워두세요. 여백이 넉넉해야 고급 사이트 느낌이 납니다. 2/4

**[3/4]**
3. **순수한 검정색(#000000) 쓰지 말기**  
흰 배경에 쌩검정 글씨를 쓰면 눈이 피로하고 촌스러움.  
살짝 톤을 낮춘 짙은 차콜 그레이(`text-slate-800` or `#1e293b`)를 쓰면 텍스트가 훨씬 부드럽고 세련되게 박힙니다.

지피티나 클로드한테 코드 수정시킬 때 딱 한 줄만 치세요.  
👉 *"전체 텍스트 색상을 #1e293b로 바꾸고 행간 1.6, 섹션별 상하 패딩은 100px로 여유 있게 다시 잡아줘."* 3/4

**[4/4]**
코딩 실력보다 중요한 건  
사용자의 눈을 편안하게 만드는 **'여백과 타이포그래피의 기본기'**입니다.

홈페이지 만들 때 이 3가지만 지켜도  
"이거 어디 에이전시에 맡겼냐"는 소리 무조건 듣습니다.  
만들 때 참고할 수 있게 저장해 두세요. 4/4

### - [ ] [글 02] SEO/카톡 공유: 링크 보냈을 때 썸네일 예쁘게 뜨게 하는 OG(Open Graph) 태그
**[1/4]**
공들여서 웹사이트 만들고 카카오톡이나 스레드에 링크 공유했는데  
빈 박스만 덜렁 뜨거나 엉뚱한 로고 떠서 없어 보였던 적 있으신가요?

링크 보냈을 때 대표 이미지와 카피가 깔끔하게 박히게 만드는  
HTML 필수 메타태그(Open Graph) 세팅법: 1/4

**[2/4]**
SNS는 링크를 올리면 그 사이트의 `<head>` 안에 있는 **'OG 태그'**를 긁어옵니다.  
이게 없으면 카톡은 미리보기를 아예 안 띄워줌.

AI한테 홈페이지 코드 짤 때 이것만 복붙해서 넣어달라고 하세요:

```html
<meta property="og:title" content="기업/브랜드/서비스명 - 한 줄 소개">
<meta property="og:description" content="클라이언트·고객의 시선을 사로잡는 핵심 혜택 2줄">
<meta property="og:image" content="https://내사이트.com/og-image.jpg">
<meta property="og:url" content="https://내사이트.com">
```
2/4

**[3/4]**
이미지 사이즈는 가로 `1200px`, 세로 `630px` (약 1.91:1 비율)로 만드는 게 국룰임.  
캔바(Canva)나 미리캔버스에서 '링크 공유 썸네일' 템플릿 쓰면 1분 만에 만듭니다.

수정하고 배포했는데도 카톡에서 옛날 이미지가 뜬다면?  
👉 **"카카오 개발자 도구 - OG 캐시 삭제"** 검색해서 내 링크 캐시 초기화 누르면 1초 만에 최신 이미지로 바뀝니다. 3/4

**[4/4]**
클라이언트한테 사이트 납품할 때 카톡 링크 보냈는데  
대표 사진이랑 문구 예쁘게 딱 뜨면 그 순간 신뢰도가 2배로 뜁니다.  
배포할 때 꼭 챙기세요. 4/4

### - [ ] [글 03] AI 프롬프트 팁: 지피티한테 "한 번에 다 짜줘" 하면 100% 망하는 이유
**[1/4]**
"지피티한테 웹사이트 만들어달라고 했는데 코드가 중간에 뚝 끊기고 에러만 잔뜩 나요."

이러는 분들의 99%는 프롬프트를 이렇게 칩니다:  
*"회원가입, 게시판, 결제 다 되는 쇼핑몰 사이트 완성 코드로 한 번에 짜줘."*

AI로 코딩할 때 절대 실패하지 않는 **'모듈형 디렉팅'** 원칙: 1/4

**[2/4]**
AI는 한 번에 출력할 수 있는 토큰(단어 수) 한계가 있습니다.  
전체 사이트를 한 번에 짜달라고 하면  
중간에 코드를 생략하거나 대충 넘어가서 버그 덩어리가 됨.

건물 지을 때 벽돌부터 쌓듯이 코딩도 쪼개서 시켜야 함. 2/4

**[3/4]**
성공하는 3단계 순서:

1. **구조만 먼저:** "화면 레이아웃과 컴포넌트 목록만 먼저 텍스트로 정리해 줘."  
2. **헤더 & 히어로 섹션:** "위 구조에서 상단 메뉴바와 메인 히어로 섹션 코드만 먼저 짜줘."  
3. **다음 섹션 연결:** "방금 짠 코드 아래에 들어갈 '고객 후기 카드 그리드' 코드 이어서 작성해 줘." 3/4

**[4/4]**
작게 쪼개서 지시할수록 AI의 코드 퀄리티는 10배 올라가고  
에러 발생 확률은 90% 줄어듭니다.  
앞으로 지피티 쓸 때 꼭 한 블록씩 시켜보세요. 4/4

### - [ ] [글 04] 타이포그래피: 상업용 무료이면서 실패 없는 한글 웹폰트 추천 3대장

상업적 이용 가능(무료)하면서

HTML `<head>`에 Pretendard CDN 링크 한 줄만 넣으면 설치 끝남:  
`<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/orioncactus/pretendard/dist/web/static/pretendard.css">` 3/4

**[4/4]**
폰트 하나만 제대로 바꿔도  
웹사이트 전체 분위기가 180도 달라집니다.  
새 프로젝트 시작할 때 꺼내 볼 수 있게 저장해 두세요. 4/4

### - [ ] [글 05] 버그 대처법: AI가 짜준 코드 빨간 에러 떴을 때 멘붕 안 오는 3단계 공식
**[1/4]**
열심히 AI 돌려서 코드 만들었는데,  
브라우저 열었더니 하얀 백지만 뜨거나 터미널에 시뻘건 영어 에러 뜰 때.

심장 쿵쾅거리고 창 닫고 싶어지죠?  
개발자들도 매일 겪는 일입니다. 당황하지 않고 10초 만에 해결하는 3단계 공식: 1/4

**[2/4]**
1. **브라우저 콘솔 열기 (`F12 → Console`)**  
화면이 멈췄을 땐 무조건 브라우저 F12 눌러서 `Console` 탭을 보세요.  
거기에 빨간 글씨로 "어디 파일 몇 번째 줄에서 왜 에러가 났는지" 다 적혀있음.

2. **에러 문장 통째로 복사하기**  
해석하려고 하지 마세요. 빨간 에러 메시지를 마우스로 긁어서 복사(`Ctrl + C`). 2/4

**[3/4]**
3. **지피티한테 맥락과 함께 던지기**  
프롬프트:  
👉 *"방금 네가 짜준 코드 실행했더니 브라우저 콘솔에 이런 에러가 떴어. [에러 메시지 복붙]. 어느 파일의 어떤 코드를 고쳐야 하는지 수정한 완성 코드로 다시 줘."*

이러면 AI가 "아, 이 부분에서 변수 정의가 빠졌네요" 하면서 5초 만에 고쳐줍니다. 3/4

**[4/4]**
에러 창은 "너 코딩 못해"라고 비웃는 게 아니라,  
**"여기 오타 났으니까 고치라고 알려주는 친절한 가이드"**입니다.

에러 떴다고 절대 도망가지 마세요.  
복사해서 AI한테 던지면 끝납니다. 4/4
