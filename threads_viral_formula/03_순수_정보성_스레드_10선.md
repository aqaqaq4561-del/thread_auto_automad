### [글 1] 디자인/UX: 촌스러운 웹사이트 1초 만에 고급스럽게 바꾸는 3대 치트키
**[1/4]**
AI로 홈페이지 만들었는데  
"기능은 다 되는데 왜 이렇게 아마추어가 만든 것처럼 촌스럽지?"

CSS/UI 치트키 3가지: 1/4

**[2/4]**
1. **폰트 행간(Line-height)은 무조건 `1.6 ~ 1.7`**  
AI가 기본으로 짜준 코드는 글자 간격이 다닥다닥 붙어있어서 답답해 보임.

2. **섹션 위아래 패딩(여백)을 2배로 늘리기**

PC 기준 섹션 상하 여백을 최소 `80px ~ 120px` 이상 시원하게 비워두세요. 여백이 넉넉해야 고급 사이트 느낌이 납니다. 2/4

**[3/4]**
3. **순수한 검정색(#000000) 쓰지 말기**  
흰 배경에 쌩검정 글씨를 쓰면 눈이 피로하고 촌스러움.  
살짝 톤을 낮춘 짙은 차콜 그레이(`text-slate-800` or `#1e293b`)를 쓰면 텍스트가 훨씬 부드럽고 세련되게 박힙니다.

지피티나 클로드한테 코드 수정시킬 때 딱 한 줄만 치세요.  
👉 *"전체 텍스트 색상을 #1e293b로 바꾸고 행간 1.6, 섹션별 상하 패딩은 100px로 여유 있게 다시 잡아줘."* 3/4

**[4/4]**

### [글 2] 보안/백엔드: Supabase 쓸 때 RLS(Row Level Security) 안 켜면 생기는 대참사
**[1/4]**
바이브코딩으로 Supabase 연동해서  
회원가입이나 문의 폼 받는 분들,  
지금 당장 대시보드 들어가서 이거 확인하세요.

**"RLS (Row Level Security)"**

이거 체크 하나 안 해두면,  
누군가 당신의 DB 데이터를 클릭 몇 번으로 전부 털어갈 수 있습니다. 1/4

**[2/4]**
Supabase에서 테이블 만들 때 기본적으로 RLS가 꺼져 있는 경우가 있음.  
RLS가 꺼져 있다는 건 뭐냐?  
**"아무나 익명으로 내 DB 테이블에 SELECT(조회), DELETE(삭제) 쿼리를 날려도 서버가 활짝 문을 열어준다"**는 뜻임.

브라우저 F12 개발자 도구 열 줄 아는 사람도  
API 엔드포인트 따서 고객들 이름, 전화번호 싹 긁어가거나  
테이블 전체를 날려버릴 수 있습니다. 2/4

**[3/4]**
해결법은 딱 1분이면 끝남.

1. Supabase 대시보드 → Table Editor 이동  
2. 만든 테이블 우측 상단 `RLS disabled` 클릭해서 `Enable RLS`로 켜기  
3. `Add Policy` 눌러서 딱 2개만 허용:  
- 일반 유저: `INSERT`만 허용 (폼 제출만 가능)  
- 관리자(Authenticated): `SELECT`, `UPDATE` 허용 (데이터 읽기는 관리자/운영자만 가능) 3/4

**[4/4]**
AI가 DB 코드 짜줬다고 무지성으로 배포하지 마세요.  
AI는 기능이 돌아가게만 만들어줄 뿐, 보안 정책까지 알아서 걸어주진 않습니다.

내가 만든 서비스가 안전한지 지금 바로 점검해 보세요. 4/4

### [글 5] 배포/도메인: 가비아에서 도메인 사서 Vercel 연결할 때 404 안 뜨게 하는 법
**[1/4]**
가비아나 호스팅케이알에서 1.5만 원 주고 도메인 샀는데,  
Vercel에 연결하니까 사이트 안 뜨고 404 에러 나서 멘붕 온 적 있죠?

개발 지식 없어도 됨.  
DNS 레코드 딱 2줄만 추가하면 1분 만에 끝나는  
가비아-Vercel 도메인 연결 공식: 1/4

**[2/4]**
Vercel 프로젝트 대시보드 `Settings → Domains`에  
내 도메인(예: `mysite.com`)을 추가하면 Vercel이 2개의 값을 줍니다.

1. **A Record:** IP 주소 (예: `76.76.21.21`)  
2. **CNAME Record:** `cname.vercel-dns.com`

이제 가비아의 `DNS 관리 툴`로 넘어가서 딱 2줄만 입력하면 끝남. 2/4

**[3/4]**
가비아 DNS 설정창에 아래처럼 넣으세요:

* **타입: A** / 호스트: `@` / 값: `76.76.21.21` (루트 도메인용)  
* **타입: CNAME** / 호스트: `www` / 값: `cname.vercel-dns.com.` (맨 뒤에 점 필수!)

이렇게 해야 `mysite.com`으로 치든, `www.mysite.com`으로 치든 둘 다 정상 접속됩니다. 3/4

**[4/4]**
설정 후 전 세계 DNS로 퍼지는 데 보통 5분~10분 정도 걸립니다.  
Vercel에서 초록색 체크(`Valid Configuration`) 뜰 때의 쾌감 느껴보세요.  
나중에 도메인 살 때 보려고 저장해 두는 거 추천. 4/4

### [글 6] SEO/카톡 공유: 링크 보냈을 때 썸네일 예쁘게 뜨게 하는 OG(Open Graph) 태그
**[1/4]**
공들여서 웹사이트 만들고 카카오톡이나 스레드에 링크 공유했는데  
빈 박스만 덜렁 뜨거나 엉뚱한 로고 떠서 없어 보였던 적 있으신가요?

링크 보냈을 때 대표 이미지와 카피가 깔끔하게 박히게 만드는  
HTML 필수 메타태그(Open Graph) 세팅법: 1/4

**[2/4]**
SNS는 링크를 올리면 그 사이트의 `<head>` 안에 있는 **'OG 태그'**를 긁어옵니다.  
이게 없으면 카톡은 미리보기를 아예 안 띄워줌.

AI한테 홈페이지 코드 짤 때 이것만 복붙해서 넣어달라고 하세요:

```html
<meta property="og:title" content="기업/브랜드/서비스명 - 한 줄 소개">
<meta property="og:description" content="클라이언트·고객의 시선을 사로잡는 핵심 혜택 2줄">
<meta property="og:image" content="https://내사이트.com/og-image.jpg">
<meta property="og:url" content="https://내사이트.com">
```
2/4

**[3/4]**
이미지 사이즈는 가로 `1200px`, 세로 `630px` (약 1.91:1 비율)로 만드는 게 국룰임.  
캔바(Canva)나 미리캔버스에서 '링크 공유 썸네일' 템플릿 쓰면 1분 만에 만듭니다.

수정하고 배포했는데도 카톡에서 옛날 이미지가 뜬다면?  
👉 **"카카오 개발자 도구 - OG 캐시 삭제"** 검색해서 내 링크 캐시 초기화 누르면 1초 만에 최신 이미지로 바뀝니다. 3/4

**[4/4]**
클라이언트한테 사이트 납품할 때 카톡 링크 보냈는데  
대표 사진이랑 문구 예쁘게 딱 뜨면 그 순간 신뢰도가 2배로 뜁니다.  
배포할 때 꼭 챙기세요. 4/4

### [글 10] 버그 대처법: AI가 짜준 코드 빨간 에러 떴을 때 멘붕 안 오는 3단계 공식
